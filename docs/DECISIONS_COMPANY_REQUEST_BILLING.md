# Company Request & Billing — Decision v1.0

Дата: 2026-08-24

## Зафиксировано

Будущий процесс добавления компании:

`Company Request → выбор услуги → Payment → paid → проверка → Identity Resolution → создание публичного профиля → сбор отзывов → Analysis → AI Summary`

### Ключевые правила

- На текущем этапе оплаты нет.
- Сейчас используется форма заявки.
- В будущем оплата может быть встроена в процесс заявки.
- Оплата не означает автоматическое подтверждение компании.
- После оплаты данные всё равно проходят проверку и Identity Resolution.
- Оплата не влияет на отзывы, их полярность, Analysis, AI Summary и любые репутационные выводы.
- Публичный профиль создаётся только после прохождения проверки и подтверждения принадлежности данных компании.
- Заявка должна иметь собственный идентификатор и статус.

## Предполагаемые статусы заявки

`submitted → under_review → approved / rejected / needs_info`

После подключения оплаты дополнительно используется статус/признак `paid`.

## Текущая реализация

Создана форма `add/index.html` без оплаты. На данном этапе форма собирает стандартные данные компании и формирует заявку для отправки.

Это промежуточная реализация до подключения backend / n8n / платежного процесса.
