# Отзыв.com

Публичный сайт независимых структурированных профилей компаний для пользователей, поисковых систем и AI-агентов.

## Рабочие адреса

- Основной сайт: https://отзыв.com/
- Первый профиль: https://ortomediya.отзыв.com/
- Инструкция для AI: https://отзыв.com/llms.txt
- Страница для AI-агентов: https://отзыв.com/ai/
- Описание услуги: https://отзыв.com/business/

## Архитектура

Этот репозиторий содержит только статический основной сайт:

```text
отзыв.com → GitHub Pages
<company>.отзыв.com → Cloudflare Worker → ограниченный Supabase RPC
```

Профили компаний не создаются отдельными репозиториями. Данные новой компании добавляются в централизованную модель Supabase, а общий Worker формирует публичный профиль по поддомену.

Cloudflare Worker, его секреты и закрытая серверная логика не должны переноситься в этот репозиторий.

## Публичные страницы

- `/` — главная и поиск компаний;
- `/about/` — о проекте;
- `/ai/` — машиночитаемые адреса и правила для AI;
- `/business/` — описание услуги для компаний;
- `/methodology/` — источники, рейтинги, отзывы, модерация и анализ;
- `/add/` — email-заявка на профиль;
- `/privacy/` — политика конфиденциальности;
- `/terms/` — условия использования;
- `/contacts/` — обращения и контакты;
- `/llms.txt`, `/robots.txt`, `/sitemap.xml` — файлы обнаружения;
- `/404.html` — фирменная страница ошибки;
- `/favicon.svg` — общий знак основного сайта.

## Правила данных

- Фактические сведения о компании отделяются от отзывов и анализа.
- Разрешённые отзывы образуют единый список с происхождением каждой записи.
- Рейтинги площадок показываются отдельно и не смешиваются в общий рейтинг «Отзыв.com».
- Публичная доступность текста не означает разрешение на копирование.
- Внешние тексты принимаются только при наличии лицензии или другого документированного законного основания.
- AI-материалы являются вторичными выводами и не представляют рекомендацию.
- Оплата подготовки профиля не даёт компании контроля над отзывами или модерацией.

Подробности: https://отзыв.com/methodology/

## Текущий статус

- Профиль «Ортомедия» работает через общий Cloudflare Worker.
- Публичная форма собственных отзывов ещё не подключена.
- Онлайн-оплата ещё не подключена.
- Тексты отзывов внешних площадок не импортируются без разрешения.

## Локальная проверка

Сайт не требует сборщика и может быть открыт любым статическим HTTP-сервером, например:

```bash
python3 -m http.server 8000
```

После запуска открыть `http://localhost:8000/`.

Перед публикацией следует проверить главную, внутренние страницы, поиск «Ортомедии», `llms.txt`, `sitemap.xml` и пользовательскую страницу 404.

## Безопасность

Никогда не добавляйте в репозиторий:

- API-токены;
- Cloudflare secrets;
- Supabase service-role key;
- Turnstile Secret Key;
- персональные email/IP пользователей;
- реальные тестовые отзывы или материалы модерации.

Статический код, отправленный браузеру, всегда доступен посетителю — независимо от видимости исходного репозитория. Секреты должны храниться только в предназначенных для этого настройках серверных сервисов.

## Публикация

Каноническая ветка — `main`. GitHub Pages публикует содержимое основного сайта на домене `отзыв.com`. После изменения необходимо проверить фактический `main` и живые URL.

Изменение видимости репозитория может остановить GitHub Pages в зависимости от тарифа. Не переводить репозиторий в private без отдельной проверки плана, резервного варианта публикации и явного решения владельца.
